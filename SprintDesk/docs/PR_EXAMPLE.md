# Проверка переназначения задач

## Что сделано

- Добавлен автоматический тест смены исполнителя администратором.
- Проверено, что предыдущий исполнитель теряет доступ к переназначенной задаче.
- Проверено, что новый исполнитель видит задачу после назначения.

## Как проверить

1. Выполнить `pytest -q`.
2. Проверить прохождение `test_admin_reassigns_task`.
3. Зарегистрировать двух участников и создать администратора.
4. Создать задачу для первого участника и назначить второго.
5. Убедиться, что второй видит задачу, а первый — нет.
