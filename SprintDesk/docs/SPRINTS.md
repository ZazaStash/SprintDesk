# Выполнение спринтов

## Спринт 1

Роли гостя, участника и администратора; user stories и модель данных; FastAPI с эндпоинтами регистрации и задач; HTML/CSS/JS-интерфейс; тесты API.

## Спринт 2

PostgreSQL в Docker Compose; SQLAlchemy ORM; две связанные сущности с проверками в Pydantic и CHECK-ограничениями; Alembic-миграция; CRUD задач через БД; отдельная тестовая SQLite-БД для каждого теста; автоматические тесты API; Git-история.

## Спринт 3

Рабочий процесс: задача → `feature/*` → commit → push → Pull Request с разделами «Что сделано» и «Как проверить» → review с approve → merge в `main` → `git pull --ff-only`.

Для защиты ветки в GitHub нужно включить запрет прямого push, обязательный PR и минимум 1 approval. Реально применить настройки к удалённому репозиторию и провести review может только пользователь с доступом к GitHub. Готовы файлы `.github/pull_request_template.md`, `.github/workflows/ci.yml`, а также автоматизация настройки через `scripts/github_setup.sh`.
